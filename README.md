# ANIMALSFANS

Site de galerias digitais, com banco Supabase e hospedagem Render Free.

Esta versão publica a interface pelo Render e conecta-se ao projeto Supabase `icwdszzcwddkxlpnlwpq`.

O painel administrativo requer uma conta Supabase Auth autorizada em `public.user_roles`. Nunca colocar chaves secretas neste repositório.
